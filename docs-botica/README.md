# Documentación de Botica LyP

Esta carpeta contiene únicamente la documentación propia de **Botica LyP**.

Botica LyP es una aplicación administrativa desarrollada en PHP sobre el framework Meralda. El núcleo del framework está incluido en `src/mwap/`, mientras que la lógica propia del proyecto se encuentra principalmente en:

```text
src/mwap/modules/pharmacy/
src/public_html/res/modules/pharmacy/
database/pharmacy_schema.sql
```
